### Proposed Solution

#### Automation 1 : Parts And Services
- Trigger: job.product_update
- Actions:
	- Update the job custom field : 'Total cost' with the current parts and service total

#### Automation 2: Invoice Status
- Triggers:
	- estimate.new
	- estimate.update
- Actions:
	- Check if the quote has a job attached 
	- If yes check if the job custom field : 'Invoice Status' = 'Yes'
	- If yes no operation
	- Else update the job custom field to 'Yes'

#### Automation 3: Update Invoice Status Default value
- Method to be used: Zuper Workflow
- Trigger: job.new
- Actions:
	- Set the value of Custom field: Invoice Status to 'Yes'
