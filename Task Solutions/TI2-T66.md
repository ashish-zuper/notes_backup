## Proposed Solution

### Automation 1
- Trigger: Quote Status Change
- Trigger status: Accepted
- Action: Create Project with :
	- Quote linked
	- customer/org from quote should be linked to project
	- project name: `<Customer First Name> <Customer Last Name>`
	- category: same category as customer

### Automation 2
- Trigger: Project New, Project update
- Scenario 1: The custom fields are filled on any day from Monday to Wednesday
	- No action to be done (this case will be handled by the scheduler)
- Scenario 2: The custom fields are filled on any day form Thursday to Sunday
	- Case 1: Frequency = Daily
		- Based on the Number of Jobs, create jobs from Monday to Friday of next week 
		- Due date should be taken from field: Due Date
			- Due date should be +1 week of the week in which we are creating jobs
			- for eg: if the trigger is received on Aug 10 (Saturday) with due date as Aug 14 (Wednesday) :
				- The due date of jobs created should be Aug 21 (Wednesday) -- *next week same day*
		- Title of the job should be :  `<Customer First Name> <Customer Last Name> - <Day> - <Job Category>`
			- For eg: If number of jobs = 2, 5x2 = 10 jobs should be created with 2 jobs for Trim category each day :
				- `Test Customer - Monday - Trim` x2 jobs
				- `Test Customer - Tuesday - Trim` x2 jobs etc..
	- Case 2: Frequency = Weekly
		- Based on number of jobs create jobs for next week
		- *Due date logic will be same as mentioned in Case 1*
		- Job Title : `<Customer First Name> <Customer Last Name> - Weekly - <Job Category>`
			- For eg: If number of jobs = 2,  2 jobs should be created with 2 jobs for Trim category each week :
				- `Test Customer - Weekly - Trim` x2 jobs

### Automation 3
- n8n scheduler 
- Frequency: weekly
- trigger day: Thursday
- Get all projects with filters:
	- status not equal to Completed or Cancelled
	- Due Date > today
	- End Date > today
- Check if custom fields under Job Configuration group is empty
- If empty, do no operation
- Case 1: Frequency = Daily
	- Due date: 
		- get the day from the Due Date field
		- set due date as: current date + 2 weeks on the same day as Due Date day
		- For eg: If Due Date is Aug 7 and current date is Aug 22, the due date should be:
			- Aug 22 + 2 weeks = September 5 (Thursday)
			- Aug 7 is Tuesday so, the final due date will be : September 3 (Tuesday)
	- All other conditions will be same as Automation 2 Scenario 2 Case 1
- Case 2: Frequency = Weekly
	- Due date logic same as case 1 and other logic to be copied from Automation 2 Scenario 2 Case 2
