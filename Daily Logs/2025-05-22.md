## Amway Meeting

### Process

check if product serial no exists
if no exit flow
api to get asset from zuper and api to get asset from gwms
if asset not found in either, exit flow
find abo number from either zuper asset or gwms asset
if not found, exit flow  --- link asset
using abo number api to search customer in zuper and api to search in mdms
if customer not found, exit flow --- asset conditions and link
if customer found in mdms but not in zuper, then create customer
if customer found in zuper, fetch customer
associate customer to job
if zuper asset found, link to job
if not
then check if base sku exists in asset
if not exit flow
fetch product using base sku and find product
create asset using mdms asset info
associate asset to job
		

### Edge Cases
- customer exists in job is mismatching with the customer found via enrichment --- secondary customer 


### Failure Cases - Job Enrichment
- Product Serial Number does not exist in job 
	- Error Message: Product Serial No missing
	- Can Retry : NO
	- Process Blocked: YES
	- How can the user enter the product serial number? The custom field is read only and the user will not be able to edit and enter the serial number to retry
- Asset Not Found in Either Zuper or GWMS
	- Error Message: Invalid Product Serial No. NOT FOUND
	- Can Retry: NO
	- Process Blocked: YES
	- User cannot edit custom field
- ABO Number Not found in asset
	- Error Message: ABO Number NOT FOUND in Asset
	- Can Retry: YES
	- Process Blocked: NO (Asset will still be linked )
	- Action: 
		- If Zuper Asset, update Asset Custom field: Ordering ABO Number
		- If GWMS Asset, update in GWMS
- Customer Not Found in either zuper or mdms
	- Error Message: Invalid ABO : `ABO_NUMBER` . NOT FOUND
	- Can Retry: YES
	- Process Blocked: NO (Asset will still be linked )
	- Action:
		- Update ABO Number in Zuper/GWMS Asset
- BaseSKU Missing in GWMS for (Create Asset Scenario)
	- Error Message: BaseSKU MISSING in Asset
	- Can Retry: YES
	- Process Blocked: YES (cannot link asset)
	- Action: 
		- Update BaseSKU in GWMS
- Product Not found in zuper during search (Create Asset Scenario)
	- Error Message: Product SKU `BASE_SKU` does not exist in Zuper
	- Can Retry: YES
	-  Process Blocked: YES (cannot link asset)
	- Action: 
		- Create Product in Zuper
- Customer Missmatch 
	- Error Message: Customer Missmatch 
	- Can Retry: NO
	- Process Blocked: NO (Asset Can still be sycned)
	- Action:
		- Sync as secondary customer (pending confirmation)
