### API-4934 — Preferred Supplier
*Repo:* `master_service` · *Branch:* `API-4934` · *Ticket:* [API-4934 — Preferred Supplier](https://linear.app/zuperinc/issue/API-4934/preferred-supplier) · *Commits:* `0fd9cf5d5` `f96000806`

- Added a per-company "preferred supplier" across the connected SRS/ABC/QXO integrations, set via a new admin-only endpoint that validates the supplier is connected and has at least one branch (and demotes any prior choice). Also added a read endpoint returning the preferred supplier with its favorite branch populated, and surfaced the preferred flag on the provider list.
- Quote (CPQ estimate) vendor-branch prefill now deterministically uses the preferred supplier's favorite branch when more than one supplier is connected — the branch shown for the preferred supplier is exactly the one quotes get prefilled with. When no preference is set it falls back to any connected supplier's favorite branch, so existing single-supplier accounts don't change.
- Kept selection strictly manual — no auto-default or backfill — so behavior stays predictable; the cross-supplier availability fallback (pick the preferred supplier's branch when the chosen vendor doesn't carry a product) is deferred to a follow-up.
