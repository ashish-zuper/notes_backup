### API-7196 — custom objects review follow-ups
*Repo:* `master_service` · *Branch:* `api-7196-custom-objects-review-follow-ups` · *Ticket:* [API-7196 — Custom Objects: review follow-ups](https://linear.app/zuperinc/issue/API-7196/custom-objects-review-follow-ups) · *Commits:* `d65b00a83`

- Custom object records now keep their attachments on the record in the same shape jobs do, with add, rename and remove routes under `/objects/:module/:record_uid/attachments`, so the web app's existing attachment panel works for custom objects.
- The routes need the record's edit right, refuse archived objects and objects with attachments turned off, log each file in the record's activity and send webhook events; a rename also renames the gallery copy, and removing a file keeps it in the gallery, as for jobs.
- Record details now return these stored attachments, and the attachment count is the number of files on the record; the shared attachment list API is back to its original code.
