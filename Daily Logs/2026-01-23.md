## Required fields

-  industry (should be alpha numeric value)
- region
- company login name 
- company logo (optional)
- address
- country 
- currency (set to USD if not provided)
- company timezone (set to los angeles if not provided)
- email
- company status
- should migrate data (requires a boolean value true or false. if true will migrate data from clone account selected)
- from_company_ref_date
- migration type 
	- we have 2 options for migration: just configs or configs + data
	- Configs: will only migrate the configs of the clone account alone without the data
	- Configs And Data: both configs and data will be migrated 
	- by default kept as Configs and Data
- modules
	- list of modules which should be enabled for the company 
	- if clone account option is chosen then the selected clone source accounts modules will be automatically copied
