### API-6845 — Custom object record activity, events and notes
*Repo:* `master_service` · *Branch:* `api-6845-03-extras` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `dcdc711b4`

- Custom object records now get activity log entries (create, field changes, owner change, delete, link and unlink), shown only while the object's activity log is on.
- Records send webhook events (`custom_object_record.new`, `.update`, `.delete`, `.link`, `.unlink`, `.new_note`) under fixed names, since object keys differ per company; the payload says which object.
- Event payloads carry short user summaries instead of full user details, and update events list each changed field with its before and after value.
- Notes work on records through the existing notes API, checked against the object's notes switch, archive state and the user's record access; attachments already work through the existing attachment routes.
- The custom object entry in the webhook event list is held back until the notification service confirms it delivers these events.
