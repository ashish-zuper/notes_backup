### API-7255 — Service package vendor rules (PR #3046 review fixes)
*Repo:* `master_service` · *Branch:* `api-7255-service-packages-add-supplier_type-and-vendor_uid` · *Ticket:* [API-7255 — Service Packages: Add supplier_type and vendor_uid with supplier filter](https://linear.app/zuperinc/issue/API-7255/service-packages-add-supplier-type-and-vendor-uid-with-supplier-filter) · *Commits:* `337cfb4dd`

- Fixed service package updates wiping the vendor: sending back a package with `supplier_type: null` no longer clears it. Only `vendor_uid: null` clears the vendor and supplier, and leaving `vendor_uid` out keeps them.
- On update, `supplier_type` is now always taken from the vendor. Re-sending the same vendor skips validation, so a package whose vendor was later deleted or disconnected can still be edited.
- Subcontractors can no longer be set as a package's vendor.
- Clearer errors: an unknown vendor now returns 400 "The selected vendor was not found" (was a 404 about a supplier branch). Picking a supplier that isn't set up or connected now says it isn't connected.

### API-7266 — Custom objects: record PATCH, association counts, populated associations
*Repo:* `master_service` · *Branch:* `api-7266-custom-objects-review-follow-ups-nov-20` · *Ticket:* [API-7266 — Custom Objects: review follow-ups (Nov 20)](https://linear.app/zuperinc/issue/API-7266/custom-objects-review-follow-ups-nov-20) · *Commits:* `d2da363e4`
*Repo:* `real_time_update_service` · *Branch:* `api-7266-custom-object-association-counts` · *Commits:* `c80909c`

- Custom object records can be updated with `PATCH /objects/:module/:record_uid`, sending the fields flat in the body with the same entry shape as `PATCH /custom_fields`, so they work like other modules' PATCH routes. Unknown or read-only keys are refused.
- Records now carry stored `association_counts` (notes, attachments and links per association) in lists, filters and details, replacing the counts that were computed on every details read. The real time service recounts them on the existing record, link, note and attachment events, as it does for job counts. Deleting a note now emits `custom_object_record.delete_note`.
- `populate_associations=true` adds associations to the object settings list and details, and link panels to record details. Record lists don't take it, since no list column shows linked records.
- Opened master_service #3056 (stacked on #3009) and real_time_update_service #193; the two must deploy together.
