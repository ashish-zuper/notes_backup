## Dev log

### hotfix_PO_line_items_update — relax PO line-item edit restriction

*Repo:* `master_service` · *Branch:* `hotfix_PO_line_items_update` · *Commits:* `09addcfa3`

- Purchase Orders from integrated suppliers could only have their line items edited until the PO was fulfilled/finalized. Removed that limit — line-item-only edits are now allowed at any supplier-locked status, matching the existing no-restriction behaviour for non-integrated vendors.
- Field edits on POs already live at the supplier stay blocked; only the line-item lock was lifted. Dropped the now-unused status constant backing it.

### API-4477 — SRS bug bash

*Repo:* `master_service` · *Branch:* `API-4477` · *Ticket:* [API-4477 — SRS - bug bash - 9/6](https://linear.app/zuperinc/issue/API-4477/srs-bug-bash-96) · *Commits:* `06b805954`

- Imported supplier products were missing their `product_no`. The import created products via an upsert, which skips the auto-increment hook that assigns the number; switched new-product creation to a normal save so `product_no` is populated, while keeping the import idempotent so re-runs don't duplicate products.

### API-4425 — Add SRS catalog item to PO (branch availability + pricing)

*Repo:* `master_service` · *Branch:* `API-4425` · *Ticket:* [API-4425 — Add Item from SRS Catalog](https://linear.app/zuperinc/issue/API-4425/add-item-from-srs-catalog) · *Commits:* `4ec5551e3`

- The "add SRS catalog item to a PO" modal needs to show only the option/UoM combos a branch actually stocks, with live prices. The supplier master product details API already returns a per-UoM price matrix per variant when a preferred vendor is passed, so extended that instead of adding a new endpoint.
- Each variant's `vendor_cost[]` entry now carries an `is_available` flag (false when SRS prices the combo as "Item not Found") plus the supplier fields the flow needs — `item_code`, `variant_code`, `price_uom`, `requested_uom`, `uom_conversion_factor`, availability. All additive; existing fields unchanged.
- Added an opt-in `available_only=true` query param that returns only branch-available combos (and hides variants with none). Default still returns everything flagged, so callers choose whether to filter.
