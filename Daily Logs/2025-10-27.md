**First Non-Repeating Character Function**

Here is the **JavaScript interview question** along with a **clear explanation and answer**:

---

### **Question: Find the First Non-Repeating Character**

Given a string, write a function to return the **first non-repeating character**.  
If all characters repeat, return `null`.

**Example:**

```
Input: "aabbcddce"
Output: "e"
```

---

### ✅ **Approach**

1. **Count frequency** of each character using a hashmap (object in JS).
    
2. **Loop through the string again** and find the first character whose count is **1**.
    

This ensures correct order and efficient lookup.

---

### ⭐ **Solution (JavaScript)**

```javascript
function firstNonRepeatingChar(str) {
  const freq = {};

  // Step 1: Count occurrences of each character
  for (const ch of str) {
    freq[ch] = (freq[ch] || 0) + 1;
  }

  // Step 2: Find the first character with frequency = 1
  for (const ch of str) {
    if (freq[ch] === 1) {
      return ch;
    }
  }

  return null; // If no non-repeating char found
}
```

---

### 🔍 **Example Run**

```javascript
console.log(firstNonRepeatingChar("aabbcddce")); // Output: "e"
console.log(firstNonRepeatingChar("xxyzx"));     // Output: "y"
console.log(firstNonRepeatingChar("aabb"));      // Output: null
```

---

### 💡 **Time Complexity**

|Operation|Complexity|
|---|---|
|Counting characters|O(n)|
|Finding first unique|O(n)|
|**Total**|**O(n)** — Efficient|
