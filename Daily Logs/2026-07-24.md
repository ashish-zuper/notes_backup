## Dev log

### API-5108 — associated_supplier_provider in GET product endpoints

*Repo:* `master_service` · *Branch:* `API-5108` · *Ticket:* [API-5108 — Add support for associated_supplier_provider in all GET product endpoints](https://linear.app/zuperinc/issue/API-5108) · *Commits:* `7c8081669`

- GET product APIs now return each product's supplier-integration link (`supplier_provider_uid`, `supplier_provider_type`) so clients can tell which products are tied to a supplier (SRS/ABC/QXO) — e.g. mobile hiding location for supplier-integrated items.
- The product list and detail endpoints already exposed these; the group-details endpoint didn't, so it gained them plus `is_supplier_imported_product` for parity.
- Also dropped a dead `link_type` projection that referenced a non-existent field. Provider name was deliberately left out (not stored on the product and not resolved by any existing API), and no primary keys are exposed.

### API-4971 — smarter supplier product search & recommend matching

*Repo:* `master_service` · *Branch:* `API-4971` · *Ticket:* [API-4971 — Optimize Recommend API to generate smarter results](https://linear.app/zuperinc/issue/API-4971/optimize-recommend-api-to-generate-smarter-results) · *Commits:* `5517d3f34`

- The recommended-supplier-products API no longer misses matches whose words appear in a different order or in part. The old logic required *every* word of the name to be present (an AND match) and discarded partials before ranking; it now uses word-order-tolerant fuzzy scoring (fuzzball token_set_ratio) with a penalty for clashing sizes/grades, so the right supplier product surfaces even when the name is reordered or abbreviated.
- The supplier catalog keyword search now tolerates word order, looks inside variant names, and also matches item numbers and variant SKUs; the search term is trimmed first. Result shape, paging and total counts are unchanged.
- Factored the shared matching logic — tokenization that keeps grade sizes like "5D", brand-compound splitting ("PrimeSource" → "prime source"), and synonym expansion — into one reusable module used by both endpoints. Full typo tolerance and relevance ranking via Atlas Search is planned as a follow-up; this in-app phase remains the fallback.
