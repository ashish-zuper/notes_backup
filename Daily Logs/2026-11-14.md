### API-6845 — Custom object review changes: record numbering
*Repo:* `master_service` · *Branch:* `api-6845-06-review-changes` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `2abe62a5d`

- New custom objects number their records without zero-padding by default (PRM-1 instead of PRM-0001); objects that already chose a padding keep it.
- Admins can set the number records start from, when creating an object or later; it can only move forward, so a record number is never given out twice.
- The starting number is kept only on the object's record counter, the same counter the company counter settings edit, and object details show the number the next record will get.
