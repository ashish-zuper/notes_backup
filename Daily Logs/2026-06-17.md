### API-4466 — ABC Supply order-template import & branch catalog creation

*Repo:* `master_service` · *Branch:* `API-4466` · *Ticket:* [API-4466 — Order Template Product Import and Catalog Creation Based on Branch](https://linear.app/zuperinc/issue/API-4466/order-template-product-import-and-catalog-creation-based-on) · *Commits:* `08496999a` `95ea02f60`

- Importing an ABC Supply order template now creates branch-scoped product catalogs the way SRS does: each template product becomes a Zuper product with a per-branch price and a vendor-catalog entry across the connected ABC branches (previously the template was saved and nothing else happened).
- Built the ABC product adapter end to end — normalize catalog items, fetch items on demand, gate catalog creation on the per-branch item-availability API, and price each product. Pricing always uses the parent item number and applies that price to all of the item's variants; ABC "Call for pricing" responses import at price 0 with the message preserved rather than failing.
- Dimensional items (sold by length, e.g. metal track in 8/10/12 ft) import as one product per length, identified `itemNumber_value_uom` (e.g. `362T125.20EQ_8_ft`), with the parent item recorded separately for pricing/ordering.
- Fixed repeat imports silently doing nothing: the import job used a fixed id and the queue retained the completed job, so subsequent imports for the same provider were dropped — the job now clears on finish so re-imports run.
- Accept numeric ABC template ids on the import request, and extend the supplier master-products schema with the ABC fields (exact item id, dimensional value, family, image asset, available branches, availability message).
