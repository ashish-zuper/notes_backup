## Dev log

### API-6845 — Custom object record list meta
*Repo:* `master_service` · *Branch:* `api-6845-05-list` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `f9b4b81b4` `6e18a5055`

- Added a filter meta API for custom object records, in the same shape as other modules: the record's own fields (Record ID, dates, owner, creator) and the custom fields the user can filter on, each with its operators and options.
- The meta and the filter API share one list of filterable fields, so the apps are never offered a field the filter would refuse; hidden and non-filterable fields are left out of both.
- Date filters now also take "equals", and user filters take "contains"/"not contains" only, matching other modules.
- Record field names have locale keys in all 13 languages, reusing existing translations where the same label already existed; custom field names stay as the company entered them, as in other modules.
- Added a column meta API for the record list: Record ID and the primary field (both open the record), owner, creator and dates, then every custom field the user can see, with the object's secondary fields shown by default.
- Sorting by the Record ID column orders records by their number, so IDs stay in order even if the object's prefix changes; columns, filters and filter meta now use one rule for which fields a user can see.

### API-6845 — Custom object bulk actions over a filter
*Repo:* `master_service` · *Branch:* `api-6845-05-list` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `f9c0110c0`

- Bulk update and bulk delete on custom object records can now pick records by filter as well as by selection, as other modules do; sending both acts only on the selected records that match the filter, and an empty filter selects every record the user can reach.
- The filter is resolved to a fixed set of records when the request is made, and a request matching more records than the company's bulk limit is refused.

### API-6845 — Custom object quick filters
*Repo:* `master_service` · *Branch:* `api-6845-05-list` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `90afc5cca`

- Saved views (quick filters) can now be created for custom object lists, and their rules can name a custom object module.
- Saving, editing or listing views for a custom object follows the object's access rules: an object the user can't see is not found, and saving views needs permission to view its records.

### API-6845 — Custom object list review fixes
*Repo:* `master_service` · *Branch:* `api-6845-05-list` · *Ticket:* [API-6845 — Custom Objects: records and links](https://linear.app/zuperinc/issue/API-6845/custom-objects-records-and-links) · *Commits:* `9a750cc77`

- Date filters on custom object records use the company's timezone when the request sends none, as other modules do, instead of UTC.
