### API-4557 — ABC pricing across all vendor-catalog flows + reconnect fix
*Repo:* `master_service` · *Branch:* `API-4557` · *Ticket:* [API-4557 — Add ABC Master Product Support to Supplier Product Linking API (single local product)](https://linear.app/zuperinc/issue/API-4557/add-abc-master-product-support-to-supplier-product-linking-api-single) · *Commits:* `ba4cdf0f2`

- Extended the ABC pricing fix to the remaining flows that create or refresh vendor catalogs: supplier-product linking (single and bulk), repricing of affected catalogs, and catalog creation when a new branch is connected. These previously priced ABC products as if they were SRS, so ABC catalogs were created with a 0 cost.
- Fixed a false "reconnect required" failure: several supplier-provider calls (both request-path and background jobs) weren't given the stored refresh token, so once an ABC access token expired they couldn't refresh it and wrongly flagged the integration as disconnected. They now receive the refresh token.
- SRS behavior is unchanged throughout (ABC-specific handling is gated by provider type, and SRS never uses the refresh token).
