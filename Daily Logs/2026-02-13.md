Step 1: Update the backend
- Backend n8n: https://internalwf.zuper.co/workflow/ow2q4Qx96usXqN0h
- Update the nodes: Configs, Configs 1
	- in the configs object, add a new entry for the company_uid along with other information 
Step 2: Update the code
- if any ui customization is required specifically for the customer, need to implement that in the next.js application 
- to run app: npm run dev
Step 3: Build the app
- to deploy the app we need to first take build
- go to the next.js app from previous step and in terminal run:
	- npm run build
Step 4: Raise PR
- repo: https://github.com/ZuperHQ/ps_static_html
- steps
- create a new folder with a unique name (folder name should not have any spaces. Can follow snake case)
- in the folder put the build folder contents
- ensure that the base path is set correctly
  ```
  git checkout main
  git pull
  git checkout -b <feature_branch_for_current_project>
  git add .
  git commit -m "descriptive commit message"
  git push origin <feature_branch_for_current_project>
  ```
- then create a PR from your feature branch to main 
- review and merge PR

Step 5: Create a new release with a unique tag from the github repo
Step 6: Go to jenkins
- open `ps_static_code_deployment`
- go to Build with Parameters
- select the tag created in step 5
- click on build

Once deployment is complete the app can be found at:
https://static.zuperpro.com/<Repo Folder Name from Step 4>/index.html
