### API-4634 — Generic outbound rate limiting (ABC)

*Repo:* `master_service` · *Branch:* `API-4634` · *Ticket:* [API-4634 — Implement Generic Rate Limiting](https://linear.app/zuperinc/issue/API-4634/implement-generic-rate-limiting) · *Commits:* `5f142efe3`

- Added a generic, Redis-backed leaky-bucket rate limiter (`lib/outbound_rate_limiter.js`) reusable for any external system, and routed every ABC Supply API call through it so ABC's per-second, per-API-group limits on the shared app credential are respected across all pods.
- Background import calls wait as long as needed for budget; live request-path calls wait only briefly then proceed (fail open), so a user request is never held behind a saturated import.
- Fixed a sandbox-vs-production detection bug that applied the wrong limits (now detected from the ABC host instead of the Zuper base URL), removed the old hand-written batch/sleep throttling, and de-duplicated concurrent token refreshes to avoid invalidating ABC's rotating refresh token.
- Added a searchable log (`event:"abc_rate_context"`) recording whether each ABC API group ran in foreground or background.

### API-4466 — ABC import: image cache, UOM dedup, id prefix, per-UOM pricing

*Repo:* `master_service` · *Branch:* `API-4466_v2` · *Ticket:* [API-4466 — Order Template Product Import and Catalog Creation Based on Branch](https://linear.app/zuperinc/issue/API-4466-order-template-product-import-and-catalog-creation-based-on-branch) · *Commits:* `ffc0ea175`

- Imported ABC product images are now hosted once and cached on the supplier master product, then reused on re-import instead of being re-downloaded each time; an existing product's image is filled only when it has none, and a non-hosted reference is never reused as an image.
- De-duplicated supplier UOMs (a repeated unit now collapses to one, preferring the orderable "stocking" entry) and preserved the UOM description, which was previously dropped — fixing duplicate/blank UOM entries on imported products.
- Imported ABC product ids are now `abc_<id>` instead of `abc_supply_<id>`.
- Supplier pricing now returns a price for every unit of measure of a product (matching the SRS pricing behaviour) rather than only the first unit.
