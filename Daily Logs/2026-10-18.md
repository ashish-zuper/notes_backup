## Dev log

### API-6389 — OAuth storage, login and consent
*Repo:* `master_service` · *Branch:* `API-6389` · *Ticket:* [API-6389 — OAuth 2.1 v1: regional authorization server + stateless front door](https://linear.app/zuperinc/issue/API-6389/oauth-21-v1-regional-authorization-server-stateless-front-door) · *Commits:* `11712ed3c` `53a67aa71`
- OAuth connections and refresh tokens now persist in MySQL (refresh tokens stored only as hashes), while short-lived codes, login sessions and revocation markers live in Redis; an hourly worker job clears expired rows.
- Added the Zuper login and consent pages for connecting apps, styled like the web app sign-in: login reuses the existing password, 2FA and lockout checks without creating a session, and users tick which permissions the app gets.
- Token audiences now come from a configurable list of resources, so a new service is one config entry, and a connection lasts up to one year as long as the app refreshes at least every 30 days.
- Verified end to end locally: region-prefixed codes and refresh tokens, consent narrowing, refresh rotation, and reuse of a code or old refresh token revoking the whole connection; 65 OAuth unit tests pass.

### API-6389 — OAuth logging
*Repo:* `master_service` · *Branch:* `API-6389-m3.5-logging` · *Ticket:* [API-6389 — OAuth 2.1 v1: regional authorization server + stateless front door](https://linear.app/zuperinc/issue/API-6389/oauth-21-v1-regional-authorization-server-stateless-front-door) · *Commits:* `e0f5270b3`
- Every OAuth log line now uses a fixed event name (for example `oauth.token.issued`, `oauth.refresh.reuse_detected`), so connections can be traced and alerted on in OpenSearch by client, grant, user and region.
- A replayed authorization code or refresh token is logged as an error for alerting; each OAuth request also gets one summary line without its query string, and token values are never logged.
- Split the OAuth work into one stacked branch per milestone so each piece can be reviewed and merged on its own while OAuth stays switched off.
