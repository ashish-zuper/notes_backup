## Dev log

### enable_worker_dev — Gate in-process worker loading
*Repo:* `master_service` · *Branch:* `enable_worker_dev` · *Commits:* `98826c7ca`

- Loading Bull workers in-process (`require('./workers')` in `app.js`) is now gated on `DEVELOPMENT_ENV_ID`, which is only set in development environments.
- Live regions run workers as a dedicated process, so requiring them in the API process is deprecated there. Reusing the existing `DEVELOPMENT_ENV_ID` signal (already used for per-deployment Bull queue prefixing) means the line no longer has to be manually commented out on every deployment.
