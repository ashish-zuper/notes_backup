### API-4961 — Add From Catalog for Quote

*Repo:* `master_service` · *Branch:* `API-4961` · *Ticket:* [API-4961 — Add From Catalog for Quote](https://linear.app/zuperinc/issue/API-4961/add-from-catalog-for-quote) · *Commits:* `1f716660e` `3f92f18f9` `5b18f212b`

- Added an optional vendor filter to the supplier master-products list: passing a vendor now scopes results to the products stocked at that vendor's branch; omitting it keeps the existing full-catalog behaviour. Works for any branch-based supplier.
- Added a new endpoint that checks, for a batch of products (optionally a specific variant), which installed vendor branches currently stock each one — verified live against the supplier (ABC and SRS). Missing/inactive products and blank inputs return empty results instead of failing the whole request, and the batch size is bounded.
- Hardened the ABC availability lookup to fetch in parallel and tolerate partial supplier errors (a single failed call no longer marks in-stock items as unavailable), with richer diagnostics for supplier timeouts; plus minor ABC sandbox request-limit and pricing-timeout tuning.
