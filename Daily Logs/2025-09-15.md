- Job Category = Delivery Method
- Job Title = Ticket Title
- Job Due Date = Current day + 3 days
- Customer = Contact
- Organization = Company 
- Line Items:
	- If ticket category = Taken:
		- Copy line items with delivery category = Taken
		- Set Job status to "Mark to Completed"
	- If ticket category = Delivery
		- Copy line items with delivery category = Delivery, post, warehouse transfer, courier line items
