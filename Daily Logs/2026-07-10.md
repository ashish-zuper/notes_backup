## Dev log

### API-4914 — ABC template import: per-family pricing + branch-availability gating
*Repo:* `master_service` · *Branch:* `API-4914` · *Ticket:* [API-4914 — Template Import updates - ABC Supply](https://linear.app/zuperinc/issue/API-4914/template-import-updates-abc-supply) · *Commits:* `e933c1710`

- ABC Supply catalog creation now prices each family item (color/style variant) individually by its own item number instead of copying the parent item's price to every variant; a $0 or "call for pricing" result is a valid catalog entry (availability, not price, decides whether an item is cataloged).
- Before creating a vendor catalog row, the item's stock is now confirmed at each branch via ABC's search-item-availability API, applied consistently across template import, bulk catalog map, and single catalog map. Items not confirmed available at a branch are not cataloged (fail-closed), so catalogs no longer contain items a branch doesn't carry.
- Fixed the master-product details endpoint so an item's displayed availability reflects real branch stock rather than pricing success — an in-stock item that returns $0 now shows as available instead of unavailable.
- ABC product category now uses the product group label (e.g. "Siding Products") instead of the noisy code-prefixed sub-category name.
